kirin プライバシーポリシー

施行日: 2026年10月15日

kirin は、書いた英語をチェックする iOS のキーボードです。このポリシーでは、kirin が何を送信し、何をどのくらいの期間保存するかを説明します。kirin は個人の開発者である Taishi Kato(以下「私たち」)が提供しています。

要点

  • 文章を送信するのは、キーボードで「全文をチェック」か「和訳で意味を確認」をタップしたときだけです。
  • 私たちのサーバーは文章を保存しません。
  • 文章のチェックは OpenAI が行います。OpenAI は文章をモデルの学習に使わず、不正利用の検知のための記録を最長30日間保存します。
  • 頼まれたときの和訳は Google が行います。Google は文章を製品の改善に使わず、不正利用の検知のための記録を55日間保存します。
  • kirin には、アカウント、広告、アクセス解析、トラッキングがありません。

送信するものと、送信するとき

  • 文章を送信するのは、kirin のキーボードで「全文をチェック」か「和訳で意味を確認」をタップしたときだけです。キーボードを表示しただけ、またはキーで文字を打っただけでは、何も送信しません。
  • 「全文をチェック」で送信するのは、入力欄の全文と、説明をその言語で返すためのアプリの表示言語です。X 以外のアプリでも、キーボードを使っていれば同じです。
  • 「和訳で意味を確認」で送信するのは、入力欄の全文だけです。
  • 英字を1文字も含まない文章は送信しません。URL など、英字を含む部分があれば、全文を送信します。
  • 文章は、Cloudflare Workers で動く私たちのサーバーを経由して言語モデルに送られます。「全文をチェック」では OpenAI の API に送られ、チェックと、直した文や言い換えの候補の作成に使われます。「和訳で意味を確認」では Google の Gemini API に送られ、ネイティブの読み手が受け取る意味のままの和訳に使われます。

サーバーが保存するもの

  • 文章: 保存しません。サーバーは文章を OpenAI か Google に渡し、結果を返すだけです。
  • 端末の登録: 不正利用を防ぐため、アプリはインストールごとに Apple の App Attest で登録します。サーバーは、端末で作られたランダムな鍵の識別子、公開鍵、カウンター、端末トークンの一方向のハッシュ、そのインストールが今の1分間と1日に行った要求の回数を保存します。この記録に、名前、メールアドレス、電話番号、文章は含まれません。サービスを提供している間、保存します。
  • IP アドレス: 端末を登録するとき、登録を試せる回数を制限するため、IP アドレスから鍵付きで作った一方向のハッシュを最長1時間保存します。IP アドレスそのものは保存しません。
  • ログ: 要求ごとに、結果、エラーの種類、文章の文字数、処理にかかった時間を短いログに残します。ログに、文章、端末トークン、IP アドレスは含まれません。

委託先

  • OpenAI は、チェックする文章を受け取ります。私たちは保存を無効にして API を呼び出します。OpenAI は API で送られた文章をモデルの学習に使いません。不正利用の検知のため、文章を含むことがある記録を最長30日間保存します。それより長く保存するのは、法令で求められた場合と、害を防ぐために必要な場合だけです。詳しくは OpenAI のプライバシーポリシーをご覧ください。
  • Google は、和訳を頼んだ文章を、Gemini API の有料枠で受け取ります。Google は有料枠で送られた文章を製品の改善に使いません。不正利用の検知と法令上の開示のため、文章を含む記録を55日間保存します。詳しくは Gemini API の利用規約と Google のプライバシーポリシーをご覧ください。
  • Cloudflare は、私たちのサーバーを動かしています。ほかのネットワークのサービスと同じく、要求を届けるために IP アドレスと要求の内容を扱います。詳しくは Cloudflare のプライバシーポリシーをご覧ください。
  • Apple は、アプリが正規のものであることを確かめる App Attest を提供しています。この確認は端末と Apple の間で行われ、私たちのサーバーは Apple と通信しません。

これ以外の第三者にデータを販売したり提供したりすることはなく、広告にも使いません。

端末に保存するもの

  • 端末トークンと登録の情報を、iOS のキーチェーンに保存します。iCloud には同期しません。
  • 候補の文に置き換えるときは、置き換えの途中でキーボードが終了した場合に備え、置き換える前の文章をキーチェーンに保存します。置き換えが終われば、すぐに削除します。途中で終了した場合は、次にキーボードかアプリを開いたときに、復旧するか破棄するかを選ぶまで保存します。
  • 同意の状態や表示言語などの設定を、アプリとキーボードが共有する保存場所に保存します。

フルアクセス

iOS では、キーボードが通信するには「フルアクセスを許可」が必要です。kirin がフルアクセスを使うのは、「全文をチェック」か「和訳で意味を確認」をタップしたときに文章を送信するためだけです。フルアクセスがなくても kirin で文字を打つことはでき、そのときは何も送信しません。

選択できること

  • アプリの同意の画面で同意するまで、何も送信しません。
  • いつでも送信をやめられます。iOS の設定で kirin のキーボードかフルアクセスをオフにするか、アプリを削除してください。
  • サーバーは名前、メールアドレス、文章を保存しないため、サーバーの記録と特定の人を結び付けることはできません。データについての質問や要望は、下の連絡先までお寄せください。

子どもについて

kirin は13歳未満の子どもを対象としておらず、13歳未満の子どもから意図して情報を集めることはありません。
